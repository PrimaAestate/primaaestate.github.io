JSON Tree

A lightweight, blazing-fast JSON tree previewer with no external dependencies.

Download on the App Store

Features ​

  • Export type declarations for Java, TS, Go and more
  • Instantly collapse and expand tree nodes
  • 100% native code, zero external libraries
  • Handles large files with lazy loading
