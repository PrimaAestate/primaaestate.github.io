Latest app releases and server-side updates across Prima Aestate apps. Server updates are listed separately from App Store version numbers.

Hello, HeroWeb CopilotServer update · v0.1.42026-11-13
Features - Gemini 4 Hydrogen is now available as an optional chat model, with a server reference multiplier of 7×. Gemini 3.5 Flash-Lite remains the default model. - Gemini 4 Argon is no longer listed. If an older version still requests Argon, the service uses Flash-Lite instead. - Default thinking levels now follow each model's official defaults. Hydrogen defaults to high and also allows an extra-high option. - Carbon's introductory and standard pricing is unchanged. In-app purchase prices are unchanged.
Hello, HeroWeb CopilotServer update · v0.1.32026-11-11
Features - Gemini 4 Carbon is now available alongside Gemini 4 Argon. Gemini 3.5 Flash-Lite remains the default model. - In app versions that support the server model list, Carbon appears after that list refreshes. Older versions may not show it. - Carbon uses the same component-based token pricing as Argon: introductory reference 11× until December 1, 2026 at 08:00 China Standard Time (UTC+8), then standard 23×. Actual deductions distinguish input, output/thinking, and cached tokens rather than applying one flat multiplier. - In-app purchase prices are unchanged.
Hello, HeroWeb CopilotServer update2026-11-10
Features - Text-token deductions are lower: server reference multipliers change from 5× to 3× for Gemini 3.5 Flash-Lite, 9× to 5× for Gemini 3.8 Flash, and 23× to 11× for Gemini 4 Argon during its introductory period (standard: 46× to 23×). The reductions differ by model, not a uniform 50% discount. - Actual deductions still price input, output (including thinking), and cached tokens separately; the reference multiplier is not one flat rate for every token. Hello, Hero - Voice-reply pricing has increased. Text input and generated audio are now charged separately, replacing the previous total-token rule. - In-app purchase prices are unchanged.
